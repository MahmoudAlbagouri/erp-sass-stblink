# المحاسبة (`accounting`)

> شجرة حسابات لكل دولة، قيود يومية لا تُعدَّل، ترحيل تلقائي لكل المستندات، قفل الفترات، والقوائم المالية.

## الغرض

دفاتر بالقيد المزدوج تُبنى من مستندات النظام نفسها: ما يُصدَر ويُعتمَد ويُصرَف
في المبيعات والمشتريات والمخزون والكاشير والتوصيل والرواتب يصير قيداً
تلقائياً، والمحاسب يضيف ما لا يعرفه النظام (رأس المال، الأصول، المصروفات)
بقيد يدوي، ثم يقرأ ميزان المراجعة وقائمة الدخل والميزانية.

## المفاهيم والقواعد

- **التفعيل مرة واحدة** (`POST /accounting/activate`، صلاحية
  `manage_accounting_settings`):
  - تُنشأ **شجرة حسابات دولة الشركة** (أو دولة يختارها) من
    `templates/chart-templates.ts`: هيكل واحد على المعيار الدولي للمنشآت الصغيرة
    والمتوسطة لكل الدول الـ 18 المسجّلة، بفروق كل دولة (اسم ضريبة المبيعات
    ووجودها، الزكاة للسعودية، ضرائب مصر، ضريبة الشركات للإمارات، مخصص نهاية
    الخدمة، الاحتياطي النظامي/القانوني).
  - **قيد افتتاحي** بأرصدة لحظة التفعيل وبنفس صيغ النظام: العملاء (لكل عميل)،
    الموردون، المخزون بمتوسط تكلفته (لكل فرع + ما في الطريق)، ما مع جهات التوصيل،
    السلف المسلّمة التي لم تُخصم، وباقي القروض — مقابل «أرصدة افتتاحية». معاملة
    REPEATABLE READ: الأرصدة لقطة واحدة ولحظة التفعيل = بدايتها.
  - النقدية والبنوك والأصول ورأس المال لا يعرفها النظام: قيد يدوي بعد التفعيل.
  - بداية الدفاتر = يوم التفعيل بتوقيت الشركة. لا قيد قبلها.
- **الشجرة**: الحسابات الرئيسية الخمسة ثابتة (أصول، خصوم، حقوق ملكية، إيرادات،
  مصروفات) ومنها نوع كل حساب وطبيعته. الكود يبدأ بكود الأب ويزيد عليه (فارغ =
  التالي تلقائياً). **التجميعي** أب لا يُرحَّل عليه، و**الفرعي** عليه القيود.
  - **حسابات النظام** (`systemKey`): يرحّل إليها القيد التلقائي بمفتاحها لا
    بكودها — يُغيَّر اسمها وكودها وموضعها، ولا تُحذف ولا تُوقف ولا تصير تجميعية.
  - حساب عليه قيود لا يُحذف (يُوقف)، ولا يصير تجميعياً. حساب تحته حسابات لا يُنقل
    ولا يتغير كوده. النقل تحت تجميعي من نفس النوع.
- **القيد** (`LedgerService.post` — المدخل الوحيد، كـ `StockService.apply`):
  متوازن، طرفان على الأقل، كل سطر طرف واحد على حساب فرعي فعّال، مقرّب لخانات
  عملة الشركة، ورقمه `JV-000001`. **لا يُعدَّل ولا يُحذف**:
  - اليدوي والافتتاحي يُعكسان بقيد معاكس (`POST /journals/:id/reverse`).
  - قيد المستند يُصحَّح بمستنده (مرتجع، إلغاء سند…) لا يدوياً.
  - لكل سطر **فرع** (مركز تكلفة) و**طرف** اختياريان (`customer`، `supplier`،
    `employee`، `courier`).
- **الترحيل التلقائي** (`PostingService` — `posting.service.ts`):
  - **منفصل عن المستند عمداً**: البيع والكاشير والمسير لا ينتظرون المحاسبة ولا
    يتعطلون بخطئها. يمر كل دقيقة (`AccountingCron`) وقبل كل تقرير وقائمة قيود،
    و«ترحيل الآن» يدوياً.
  - **لكل مستند وحدث قيد واحد**: فهرس فريد على (المصدر، المستند، الحدث). إعادة
    المرور لا تكرر شيئاً، ودورتان متزامنتان لا تتسابقان (قفل استشاري لكل شركة).
  - **الحدث بعد التفعيل بوقت وقوعه** (الإصدار، الإلغاء…): ما قبله في القيد
    الافتتاحي. إلغاء بعد التفعيل لمستند قبله يُرحَّل (يعكس أثره في الأرصدة).
  - **تاريخ القيد = التاريخ المحاسبي للمستند** (`invoiceDate`، `paymentDate`،
    `returnDate`…)؛ الإلغاء بتاريخ الإلغاء.
  - **فشل مستند لا يوقف غيره**: كل مستند في معاملته؛ السبب في
    `accounting_posting_errors` (يظهر في صفحة الإعداد) ويُعاد كل 10 دقائق حتى
    ينجح. مستند بلا أثر (مبالغ صفر) يُعلَّم في `accounting_skipped_sources`.
- **قفل الفترة** (`lockDate`): لا قيد يدوي بتاريخ مقفل. المستند المتأخر (فاتورة
  كاشير رُفعت بعد الإقفال) يُقيَّد في **أول يوم مفتوح** ويُحفظ تاريخه في
  `documentDate`. لا قفل لفترة لم تنتهِ.
- **حسابات طرق الدفع** (`receiptAccounts` / `paymentAccounts`): كل طريقة إلى أي
  حساب أصول فرعي (صندوق، بنك…). الافتراضي: نقدي ← الصندوق، تحويل ← البنك، شبكة
  ← البطاقات تحت التسوية، شيك ← شيكات تحت التحصيل. التحصيل عبر جهة توصيل
  (`courier`) دائماً على «ذمم جهات التوصيل» بطرف الجهة. الرواتب: النقدي من
  حساب «نقدي»، والبنكي من حساب «تحويل بنكي».
- **الدفاتر للشركة كلها**: المستخدم المقيَّد بفروع لا يرى المحاسبة (403)؛ غير
  المقيَّد يصفّي التقارير بفرع.

### قواعد الترحيل

| المستند والحدث | مدين | دائن |
|---|---|---|
| فاتورة بيع صادرة | العميل (الإجمالي) + تكلفة المبيعات | المبيعات (وإيراد التوصيل لسطر `DELIVERY-FEE`) + ضريبة المخرجات + المخزون |
| مرتجع بيع صادر | مردودات المبيعات + ضريبة المخرجات + المخزون (بتكلفة الفاتورة) | العميل + تكلفة المبيعات |
| سند قبض / ردّ لعميل | حساب الطريقة (أو ذمة جهة التوصيل) ↔ العميل | |
| إلغاء سند | عكس السند بتاريخ الإلغاء | |
| فاتورة شراء معتمدة | المخزون + ضريبة المدخلات (للمسجّلة في الضريبة؛ غيرها: الضريبة في التكلفة) | المورد |
| إلغاء فاتورة شراء معتمدة | المورد | ضريبة المدخلات + المخزون (بمتوسط وقت الإلغاء) ± فروقات المخزون |
| مرتجع شراء | المورد | ضريبة المدخلات + المخزون (بالمتوسط) ± فروقات المخزون |
| سداد مورد / إلغاؤه | المورد ↔ حساب الطريقة | |
| تسوية مخزون / رصيد افتتاحي | المخزون ↔ فروقات المخزون / أرصدة افتتاحية | |
| اعتماد جرد | المخزون ↔ فروقات المخزون (بقيمة الفرق) | |
| تسوية جهة توصيل | حساب الطريقة (المستلم) + مصروف التوصيل (رسومها) ± فروقات التسويات | ذمة الجهة (المحصّل) |
| تقفيل وردية بعجز/زيادة | عجز وزيادة الصندوق ↔ الصندوق (وفرق إعادة الحساب لاحقاً) | |
| حركة درج كاشير | الصندوق ↔ حركات الدرج تحت التسوية (يصنّفها المحاسب) | |
| صرف مسير | الرواتب (بعد خصم الإجازة غير المدفوعة) + البدلات + المكافآت + بدل الإجازات + نهاية الخدمة — بلا ما صُرف مباشرة | قروض وسلف الموظفين (الأقساط) + جزاءات الموظفين + حساب طريقة راتب كل موظف (الصافي)؛ خصومات فاقت المستحق: ذمة على الموظف |
| تسليم سلفة | سلف الموظفين | الصندوق |
| اعتماد قرض (`loans.approvedAt`) | قروض الموظفين | الصندوق |
| صرف مكافأة / بدل إجازة مباشرة | المكافآت / بدل الإجازات | الصندوق |
| رصيد افتتاحي لعميل/مورد أُضيف أو عُدّل بعد التفعيل | الفرق بين الحالي وما في القيد الافتتاحي (`accounting_opening_baselines`) وما رُحّل | |

- **المطابقة**: رصيد العملاء والموردين في الأستاذ = مجموع كشوفهم، والمخزون ≈ قيمة
  المخزون بمتوسط التكلفة (فروق تقريب، وتكلفة البيع بالسالب) — اختبار
  `test/accounting.e2e-spec.ts`.
- **ما لا يُرحَّل**: التحويل بين المخازن (نفس حساب المخزون)، وحركات المستندات
  قبل التفعيل (في الافتتاحي).
- **التقارير** من أسطر القيود مباشرة، وأرصدة التجميعي = مجموع ما تحته:
  - ميزان المراجعة: أول المدة وحركة الفترة والختامي، بمستوى وفرع.
  - كشف حساب: لحساب فرعي أو تجميعي (بما تحته)، برصيد متحرك وطرف (حتى 5000 سطر).
  - قائمة الدخل: الإيرادات والمصروفات، مجمل الربح (مجموعة حساب المبيعات −
    مجموعة تكلفة المبيعات)، وصافي الربح.
  - الميزانية: الأصول = الخصوم + حقوق الملكية + أرباح السنوات السابقة غير
    المقفلة + صافي ربح السنة حتى التاريخ (لا قيود إقفال: تُحسب).

## علاقته بباقي النظام

- **لا يعتمد عليه أي موديول، ولا يستورد موديولاتهم**: يقرأ جداولها (كياناتها)
  في محرك الترحيل فقط. إيقاف المحاسبة لا يمس شيئاً آخر.
- يقرأ: `sales`، `purchasing`، `inventory` (حركات المخزون بمرجعها)، `delivery`،
  `pos` (الورديات وحركات الدرج)، `payroll`، `salaries` (طريقة الدفع)،
  `advances`، `loans`، `bonuses`، `settlements`، `employees` (الفرع).
- `inventory`: كل طلب تسوية مخزون له `referenceId` (به يُجمع في قيد واحد).
- `loans`: `approvedAt` يُضبط عند الاعتماد.
- ميزة الباقة: `accounting_module`.

## صفحات الواجهة

- `/dashboard/accounting` — التفعيل (اختيار الدولة ومعاينة شجرتها)، بداية
  الدفاتر وقفل الفترة، حسابات طرق القبض والدفع، ومستندات تعذّر ترحيلها مع
  «ترحيل الآن».
- `/dashboard/accounting/chart` — الشجرة: فتح وطي، بحث، إضافة تحت حساب، تعديل،
  نقل، إيقاف، حذف، وكشف حساب لكل حساب.
- `/dashboard/accounting/journals` — دفتر اليومية بفلاتر المصدر والتاريخ والبحث،
  عرض القيد بأسطره، القيد اليدوي (مسودته محفوظة على الجهاز) وعكسه.
- `/dashboard/accounting/ledger` — كشف حساب برصيد متحرك (`?accountId=`).
- `/dashboard/accounting/trial-balance` — ميزان المراجعة (مدين/دائن لكل عمود).
- `/dashboard/accounting/statements` — قائمة الدخل والميزانية.
- كل التقارير تُطبع (`utils/print.ts`).
