# STB ERP — كتالوج المشروع

نظام ERP سحابي متعدد الشركات (SaaS): موارد بشرية، أصناف ومخزون، مشتريات،
مبيعات، ونقاط بيع تعمل بلا إنترنت. هذا المجلد هو **مرجع المشروع**: ما فيه،
كيف يعمل، وأين تجد كل شيء.

| تريد | اذهب إلى |
|---|---|
| تجربة المسارات وحقولها وصلاحياتها | Swagger: `http://localhost:<PORT>/docs` |
| شرح موديول بعينه | [فهرس الموديولات](#فهرس-الموديولات) أدناه |
| الفروع وقيد المستخدمين بها | [branches.md](branches.md) |
| ما يعمل بلا إنترنت في المشروع (الطيار، عدّ الجرد، لوحة التحكم عند الانقطاع) | [offline.md](offline.md) |
| الكاشير والعمل بلا إنترنت | [pos-offline.md](pos-offline.md) |
| استخدام شاشة الكاشير (اختصارات، عروض، آجل، مشرف، تدقيق) | [pos-screen.md](pos-screen.md) |
| الواجهة (Nuxt) | `docs/README.md` في مشروع الواجهة `stb-erp` |
| إضافة ميزة وتسجيلها هنا | [كيف تضيف شيئاً وتسجّله](#كيف-تضيف-شيئاً-وتسجّله) |

## المشروعان

| المشروع | المسار | التقنية |
|---|---|---|
| الباك إند | `back-end/erp-sass` | NestJS 11، TypeORM 0.3، PostgreSQL |
| الواجهة | `fornt-end/stb-erp` | Nuxt 4، Vue 3، Pinia، SCSS، عربي RTL |

## التشغيل

```bash
# الباك إند
npm install
npm run start:dev          # http://localhost:3002 (أو PORT) — والتوثيق على /docs

# الواجهة
npm install
npm run dev
```

**متغيرات البيئة** (`.env` في الباك إند):

| المتغير | الغرض |
|---|---|
| `DB_HOST` `DB_PORT` `DB_USERNAME` `DB_PASSWORD` `DB_NAME` | قاعدة البيانات |
| `JWT_ACCESS_SECRET` `JWT_REFRESH_SECRET` | توقيع التوكنات |
| `PORT` | منفذ السيرفر (الافتراضي 3002) |
| `API_BASE_URL` | عنوان السيرفر العام: أصل روابط الملفات الموقَّعة (بدونه يُؤخذ من الطلب) |
| `FILES_URL_SECRET` | اختياري: مفتاح توقيع روابط الملفات (الافتراضي مشتق من `JWT_ACCESS_SECRET`) |
| `FILES_DIR` | اختياري: مجلد تخزين المرفوعات (الافتراضي `uploads/` في مجلد التشغيل) |
| `TRUST_PROXY` | اختياري: من يُوثق بترويسة `X-Forwarded-For` منه (الافتراضي `loopback` = nginx على نفس السيرفر) — به يُعرف عنوان أجهزة البصمة |
| `DEVICE_SERVER_URL` | اختياري: عنوان السيرفر لأجهزة ZKTeco (الافتراضي دومين `API_BASE_URL` على HTTP:80) |
| `BIOMETRIC_SECRET` | اختياري: مفتاح تشفير قوالب البصمات المنسوخة بين الأجهزة (الافتراضي مشتق من `JWT_ACCESS_SECRET`) |
| `MAIL_HOST` `MAIL_PORT` `MAIL_USER` `MAIL_PASS` | بريد استعادة كلمة المرور |
| `SWAGGER_ENABLED` | `true` يفتح التوثيق في الإنتاج، `false` يغلقه دائماً |
| `META_PIXEL_ID` `META_PIXEL_ACCESS_TOKEN` | تتبع التسويق |

**قاعدة البيانات تُدار بالهجرات فقط** (`src/database/migrations`): تُنفَّذ المعلّقة
تلقائياً عند تشغيل السيرفر، و`synchronize` مغلق. تغيير أي كيان بلا هجرة يفشل
في اختبار المخطط.

## بنية الباك إند

```
src/
  main.ts                 التشغيل: CORS، التحقق، Swagger، الملفات الثابتة
  app.module.ts           تسجيل كل الموديولات
  config/                 قاعدة البيانات، JWT، الترجمة، Swagger
  database/               الهجرات، وبذرة مالك النظام
  common/
    constants/            الصلاحيات، مميزات الباقات، الدول
    decorators/           @Permissions @RequiresFeature @CheckQuota @CurrentUser…
    guards/               الشركة، الاشتراك، الصلاحيات، مالك النظام
    interceptors/         تغليف الاستجابة، الرفع
    entities/             TenantOwnedEntity (أساس الكيانات التجارية)
    utils/                المال، الوقت، الهاتف، أرقام المستندات، التنسيق
    reports/              تصدير excel و pdf
  modules/<module>/       كل موديول: controller + service + dto + entities
  i18n/                   رسائل عربي/إنجليزي
test/                     اختبارات التكامل والمسارات
docs/                     هذا الكتالوج
scripts/docs-catalog.cjs  مولّد الكتالوج
```

## كيف يمرّ الطلب

```
الطلب
 → JwtAuthGuard          من أنت؟ (التوكن ← request.user)
 → TenantScopeGuard      هل لك شركة؟ (المسارات التجارية)
 → SubscriptionGuard     هل الاشتراك فعّال؟ هل الميزة في الباقة؟ هل بقي في الحد؟
 → PermissionsGuard      هل دورك يحمل الصلاحية؟
 → BranchScopeInterceptor   ما فروعك؟ (يقيّد كل ما تقرؤه وتكتبه الخدمات)
 → ValidationPipe        هل البيانات صالحة؟ (الـ DTO)
 → Controller → Service → قاعدة البيانات
 → TransformInterceptor  { success, message, statusCode, data }
```

## القواعد العامة (تسري على كل الموديولات)

**1. عزل الشركات.** كل جدول يحمل معرّف الشركة وكل استعلام يُقيَّد به. الكيانات
التجارية ترث `TenantOwnedEntity` (`tenantId` + `createdAt` + `updatedAt` +
حذف منطقي `deletedAt`). موديولات الموارد البشرية الأقدم تسمّي العمود `tenant_id`.

**2. ثلاثة أنواع مستخدمين.** مالك النظام (بلا شركة، يدير المنصة ويتجاوز الاشتراك
والصلاحيات)، مدير الشركة (كل صلاحيات شركته وكل فروعها)، وموظف (صلاحيات دوره،
وفروعه إن قُيِّد).

**3. ثلاث طبقات وصول، تُكتب على المسار نفسه:**

| الطبقة | الـ decorator | مصدر القيم |
|---|---|---|
| الصلاحية | `@Permissions(PERMS.X)` | `common/constants/permissions.ts` |
| ميزة الباقة | `@RequiresFeature(FEATURES.X)` | `common/constants/features.ts` |
| حد الباقة | `@CheckQuota('max_x')` | عدّاد `@QuotaResolverFor` في الموديول |

الصلاحيات تُكتشف تلقائياً عند التشغيل، والثلاث تظهر في Swagger وفي هذا الكتالوج
تلقائياً. مرآة الصلاحيات والمميزات في الواجهة: `app/utils/access.ts`.

**4. الفروع.** المستخدم المقيَّد بفروع لا يرى ولا يعدّل بيانات غيرها. أي قائمة
أو تقرير جديد يجب أن يستدعي دوال `modules/branches/branch-scope.ts`.
التفاصيل: [branches.md](branches.md).

**5. المال.** لا حساب بالفاصلة العائمة: `decimal.js` + `common/utils/money.util.ts`.
الأعمدة بثلاث خانات، والتقريب لخانات عملة الشركة (2 أو 3).

**6. الوقت.** يُخزَّن UTC دائماً. حدود اليوم والعرض بمنطقة الشركة:
`common/utils/timezone.util.ts`.

**7. الدول.** الدولة تحدد العملة والمنطقة الزمنية وكود الهاتف والضريبة المقترحة:
`common/constants/countries.ts` (ومرآته في الواجهة).

**8. المستندات التجارية.** مسودة بلا أثر ← اعتماد/إصدار يحرّك المخزون والحسابات
داخل معاملة واحدة. الصادر لا يُعدَّل: يُصحَّح بمستند عكسي (مرتجع). الأرقام
التسلسلية تُعطى عند الاعتماد فلا فجوات (`common/utils/document-number.util.ts`).

**9. المخزون له مدخل واحد**: `StockService.apply`، ودفتر حركاته لا يُعدَّل.

**10. شكل الاستجابة موحّد**: `{ success, message, statusCode, data }`، والأخطاء
برسائل عربية.

**11. الأحداث والإشعارات.** الموديول لا يرسل إشعاراً بنفسه: يعلن ما حدث بعد
الحفظ (وبعد الـ commit) بـ `DomainEvents.emit` (`common/events/domain-events.ts`)،
ومستمعات موديول الإشعارات تقرر من يستلم وماذا يقرأ. المهام الدورية (`@Cron`)
تُسجَّل جدولتها مرة واحدة في AppModule — لا `ScheduleModule.forRoot()` في
موديول آخر. التفاصيل: [modules/notifications.md](modules/notifications.md).

**12. الملفات المرفوعة.** لا مسار ولا رابط ملف نصاً في أي جدول، ولا خدمة ملفات
ثابتة: الملف سجل في `files`، والسجل يشير إليه بمعرّفه، ويصل الواجهة برابط موقَّع
مؤقت فقط ضمن رد مسار محمي. أي معرّف ملف يُستقبل يمر بـ `files.assertOwned`
(ملف شركة أخرى ← 400). التفاصيل: [modules/files.md](modules/files.md).

**ما هو خاص بالسعودية حتى الآن:** أسعار الباقات بالريال، فاتورة هيئة الزكاة
والضريبة (QR والسلسلة)، تصنيف جنسية الموظف والإقامة، وحساب نهاية الخدمة.

## كيف تضيف شيئاً وتسجّله

الهدف أن يبقى هذا الكتالوج صادقاً بأقل جهد: ما يمكن استخراجه من الكود يُولَّد،
وما يحتاج شرحاً يُكتب مرة.

**مسار جديد في موديول موجود**

1. اكتب فوق الدالة تعليقاً من سطر: `/** ما يفعله المسار */` — هو عنوانه في
   Swagger وفي الكتالوج.
2. ضع `@Permissions` (وأضف الصلاحية في `PERMS` وفي `access.ts` بالواجهة إن كانت
   جديدة)، و`@RequiresFeature` / `@CheckQuota` إن لزم.
3. اكتب تعليقاً فوق حقول الـ DTO التي تحتاج شرحاً (يظهر في Swagger).
4. إن كان يعرض قائمة أو تقريراً: قيّده بالفروع (`branch-scope.ts`).
5. شغّل `npm run docs:catalog`.
6. إن غيّر قاعدة أو مفهوماً: عدّل قسم «المفاهيم والقواعد» في `docs/modules/<module>.md`.

**موديول جديد**

1. أنشئ `src/modules/<module>/` وسجّله في `app.module.ts`.
2. أضف قسمه في `API_TAGS` بملف `src/config/swagger.config.ts`، وضع
   `@ApiTags(apiTag('KEY'))` على الـ controller.
3. كيان جديد = هجرة جديدة (اختبار `schema.int-spec.ts` يطبع الـ SQL الناقص).
4. شغّل `npm run docs:catalog`: ينشئ `docs/modules/<module>.md` بهيكل فارغ.
5. املأ الهيكل: السطر التعريفي (يظهر في الفهرس)، الغرض، القواعد، العلاقات،
   صفحات الواجهة.
6. أضف صفحته في الواجهة إلى `app/utils/navigation.ts`.

**حدث يستحق إشعاراً**: سطر في `DomainEventMap`، `emit` في الخدمة بعد الحفظ،
ومستمع في `modules/notifications/listeners/` (أو فاحص دوري في `scanners/`).

**حقل ملف مرفوع** (صورة، مستند): عمود `…FileId` + علاقة `StoredFile` في الكيان،
معرّف `@IsUUID` في الـ DTO، `files.assertOwned` قبل الحفظ، وتحميل العلاقة مع
السجل. الخطوات في [modules/files.md](modules/files.md).

**تغيير في قاعدة عمل** (بلا مسار جديد): عدّل شرح الموديول باليد — هذا الجزء لا
يولّده شيء.

**ما يُولَّد ولا يُعدَّل باليد**: ما بين علامتي `AUTO:START` و`AUTO:END` في أي ملف.
